# 在工状态审计钉钉小程序员工端

这是周五会议演示用的员工端小程序版本，功能保持最小闭环：

- 选择登记日期，默认当天。
- 选择管理员维护的项目。
- 填写项目权重和备注。
- 提交后进入管理员网页端审批。
- 查看当日填报记录、今日已填权重、剩余权重和待审批数量。
- 待审批记录支持员工端自行撤回，撤回后不再计入今日已填权重。

## 演示前配置

1. 确认后端 Spring Boot 已启动，默认端口为 `9090`。
2. 确认 `config.js` 中的 `apiBase` 使用本地后端地址：

```js
apiBase: 'http://127.0.0.1:9090/api'
```

3. 如需换演示员工，修改 `config.js` 中的 `demoEmployee`。
4. 使用钉钉小程序开发者工具打开本目录。

## 说明

当前版本为了稳定演示，员工身份使用 `config.js` 中的固定员工信息。正式接入钉钉时，应通过钉钉免登获取用户身份，再与系统员工表进行绑定。
